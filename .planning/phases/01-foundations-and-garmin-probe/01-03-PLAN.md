  <behavior>
    - fetchToken with stub returning 200 text "aaa.bbb.ccc\n" resolves "aaa.bbb.ccc" (trimmed); a JSON-wrapped body `{"token":"..."}` / quoted string is also tolerated.
    - fetchToken 401 throws GarminHttpError; `String(err)`, `err.message` and `JSON.stringify(err)` contain neither the key, "ApiKey" nor "Bearer".
    - When the stub fetch itself rejects with an error whose message embeds the key/headers, the wrapped error is sanitized (no key, no token, no query-string).
    - tokenExpiry decodes exp/iat from a hand-built base64url JWT; returns null on garbage.
    - classify: 429 -> rate_limited; 401/403 -> access_denied; 2xx with null/[]/{}/object of all-null-or-empty -> no_data; other 2xx -> ok; 400/5xx -> error.
  </behavior>

Implement per the interfaces block. Use only global fetch/atob/TextDecoder (must run in browsers; no `node:` imports, no Buffer). Never log. Test fixtures in tests must build fake keys at runtime (random string), not literals, so gitleaks stays clean. Export everything from `src/index.ts`.
